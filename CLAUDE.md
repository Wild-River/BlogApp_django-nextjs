## Next.js 16 — read the bundled docs first

`AGENTS.md` (above) is not boilerplate: this is Next.js **16.3.4** with React **19.2.8**, and
several App Router APIs differ from older versions. Before writing or reviewing framework code,
read the relevant guide under `node_modules/next/dist/docs/` (`01-app/`, `03-architecture/`,
`index.md`). The `<!-- BEGIN:nextjs-agent-rules -->` block in `AGENTS.md` is regenerated by
`next dev` — commit it alongside your changes rather than trying to strip it.

Version-specific things already visible in the scaffold:

- **Global route-typed prop helpers.** `app/layout.tsx` uses `LayoutProps<"/">` and pages use
  `PageProps<...>` — these types are generated by Next into `.next/types` and available globally
  with no import. Run `next dev` or `next build` after adding/moving routes so the types regenerate.
- **`params` / `searchParams` are async.** In the App Router they are Promises — `await` them
  (or `React.use()` them in Client Components).

## Commands

Package manager is **pnpm** (`pnpm-lock.yaml`; a `pnpm-workspace.yaml` sets `allowBuilds`).

| Task                              | Command                               |
| --------------------------------- | ------------------------------------- |
| Dev server (Turbopack, port 3000) | `pnpm dev`                            |
| Production build                  | `pnpm build`                          |

## Architecture

Fresh `create-next-app` scaffold — the app itself (a blog + todos, per the repo name) is not
built yet. Current shape:

- **App Router only**, no `src/` dir. Route code lives directly under `app/`.
- **`app/layout.tsx`** is the root layout: loads Geist / Geist Mono via `next/font/google` as
  CSS variables (`--font-geist-sans`, `--font-geist-mono`) and owns the `<html>`/`<body>` shell.
- **`@/*`** path alias maps to the repo root (`tsconfig.json`).

### Styling — Tailwind CSS v4, CSS-first

- No `tailwind.config.js`. All configuration is in `app/globals.css` via `@import "tailwindcss"`
  and the `@theme inline { ... }` block, which maps CSS variables to Tailwind tokens
  (`--color-background`, `--color-foreground`, `--font-sans`, `--font-mono`).
- Dark mode is driven by `@media (prefers-color-scheme: dark)` overriding the `:root` variables.
- PostCSS uses the `@tailwindcss/postcss` plugin (`postcss.config.mjs`).

### Lint

ESLint **flat config** (`eslint.config.mjs`) composed from `eslint-config-next/core-web-vitals`
and `eslint-config-next/typescript` subpath imports, with `globalIgnores` re-declared because
overriding `defineConfig` drops the preset's default ignores.
